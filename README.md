# Collect a Dataset

## Project Overview
This project focuses on collecting and organizing a dataset for data analytics purposes.

## Dataset Name
Telco Customer Churn Dataset

## Dataset Source
Kaggle: https://www.kaggle.com/datasets/blastchar/telco-customer-churn

## Dataset Description
This dataset contains information about telecom customers, including:
- Customer ID
- Gender
- Senior Citizen
- Tenure
- Internet Services
- Monthly Charges
- Total Charges
- Churn Status

## File Format
CSV (Comma Separated Values)

## Purpose
The purpose of collecting this dataset is to understand data collection and prepare data for future analysis.

## Tools Used
- Kaggle
- GitHub
- CSV
